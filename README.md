# Калькулятор цены 3D-печати

## Структура проекта

```
/workspace
├── run.py                          # точка входа: python run.py -> http://127.0.0.1:5000
├── requirements.txt                # flask (остальное — стандартная библиотека)
├── calculator.db                   # SQLite-база (создаётся автоматически при первом запуске)
└── printer_cost_calculator/
    ├── db/                         # Слой данных
    │   ├── models.py               #   Printer, Material, Consumable, Settings (dataclass)
    │   └── repository.py           #   CRUD для таблиц printers/materials/consumables + settings
    ├── logic/                      # Чистая бизнес-логика (не зависит от UI и БД)
    │   └── calculator.py           #   CalcInput -> calculate() -> CalcResult (ход расчёта + итоги)
    ├── ui/                         # Интерфейс (Flask; вкладки реализуются на след. этапе)
    │   ├── app.py                  #   каркас приложения + схема API-маршрутов
    │   └── templates/index.html    #   главная страница-меню вкладок
    └── tests/
        └── test_core.py            #   тесты БД и расчётов (python -m unittest ... — все проходят)
```

## Модель данных

### printers (вкладка «Принтеры»)
| поле | назначение |
|---|---|
| name | название принтера (для выпадающего списка) |
| electricity_kwh_per_hour | потребление электроэнергии, кВт·ч/час |
| depreciation_rub_per_hour | амортизация, ₽/час наработки |
| note | комментарий |

### materials (вкладка «Материалы»)
| поле | назначение |
|---|---|
| name | тип материала (PLA, PETG…) |
| density_g_cm3 | плотность (резерв: пересчёт объёма слайсера в граммы) |
| spool_weight_kg | масса катушки — выбор 0.5 или 1.0 кг |
| price_rub | цена за катушку |
| → price_per_gram | вычисляется: price_rub / (spool_weight_kg·1000) |

### consumables (вкладка «Расходные материалы»)
kind ∈ {napkin — салфетки, lubricant — смазка, nozzle — сопло, glue — клей};
unit, consumption_per_part (норма на деталь), price_rub. На форме калькулятора —
флажки салфетка/смазка, выпадающий список сопла и клея.

### settings
electricity_price_rub_per_kwh (тариф), labor_rate_rub_per_hour и markup_percent (зарезервированы).

## Формула расчёта (на 1 деталь)
```
ЭЛЕКТРОЭНЕРГИЯ = время(ч) × кВт·ч/ч принтера × тариф ₽/кВт·ч
АМОРТИЗАЦИЯ    = время(ч) × ₽/ч амортизации принтера
МАТЕРИАЛ       = масса изделия(г) × ₽/г материала изделия
ПОДДЕРЖКИ      = масса поддержек(г) × ₽/г материала поддержек   [только если флажок установлен]
РАСХОДНИКИ     = Σ норм расхода отмеченных позиций (на деталь)
──────────────────────────────────────────────────────────────
ИТОГ ДЕТАЛИ = сумма строк;  ИТОГ ПАРТИИ = итог детали × количество
```
Результат (`CalcResult`) содержит список `CalcStep` — ход расчёта с формулами —
и оба итога: за одну деталь и за партию.
